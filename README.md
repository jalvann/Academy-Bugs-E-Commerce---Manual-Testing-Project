
# AcademyBugs E-Commerce Manual Testing Project

## 📌 Project Overview

AcademyBugs is a demo e-commerce web application used for practicing manual software testing and defect identification.

This project focuses on validating core e-commerce functionalities through structured test planning, test scenario preparation, test case design, test execution, and defect reporting.

The objective is to apply Software Testing Life Cycle (STLC) activities and document testing results in a professional QA format.

---

## 🌐 Application Under Test

- **Application Name:** AcademyBugs
- **Application Type:** E-Commerce Web Application
- **Website:** https://academybugs.com/
- **Testing Approach:** Manual Testing

I performed the following activities:

## 🎯 Testing Objectives

- Validate the functionality of the AcademyBugs e-commerce application.
- Identify defects in application workflows.
- Verify that actual results match expected results.
- Ensure test scenarios cover positive, negative, and boundary conditions.
- Maintain structured testing documentation.
